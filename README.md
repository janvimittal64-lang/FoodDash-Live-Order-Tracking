# FoodDash — Interactive React Dashboard

Software required: Node.js, React.js, Vite, npm, VS Code.

Run:
1. Open this folder in VS Code.
2. Terminal: npm install
3. Terminal: npm run dev
4. Open the localhost link.

Interactive features:
- Sidebar navigation: Overview, Orders, Delivery Fleet, Live Tracking, Restaurants
- Search and select orders
- Click orders to update tracking panel
- Live active-delivery counter and clock
- Notification dropdown
- Map zoom + / - and center-on-rider
- Fleet Track buttons
- Restaurant cards
- Responsive layout

Viva: "This is a React-based food delivery operations dashboard. Node.js and npm provide the development environment and package management, Vite runs the development server, and React handles the interactive UI and state."
